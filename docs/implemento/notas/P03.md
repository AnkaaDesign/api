### Desvios (seguiu-se o código)

1. **`X-Client` nasce desligado** (`VITE_SEND_X_CLIENT=1` no build liga). O web fala com a API por outra origem (`api.ankaadesign.com.br`; `localhost:3030` no dev) e `x-client` **não está** em `allowedHeaders` do CORS (`api/src/common/config/security.config.ts:274`): mandado hoje, o preflight reprovaria TODA requisição do web — em produção e no dev de quem roda o web contra a api local. Quem dona a api (P06, o censo) precisa pôr `'x-client'` no CORS; só depois de isso estar em produção o build do web liga a variável. Não toquei na api (fora do escopo).
2. **Extrator com o compilador do TypeScript, não ts-morph**: `ts-morph` não está instalado em nenhum dos repos e a regra da fase é não instalar dependência sem necessidade; `typescript` já está no web e o script roda com `node` (Node 26 remove os tipos; sem `tsx`).
3. **G4 — o teste não julga `_count` curto**: o web manda `_count: { tasks: true }` (clientes) e o repositório da API o traduz para `{ select: … }` (`mapIncludeWithNestedHandling`) antes do Prisma; o teste vai direto ao Prisma e o recusaria. As 3 formas ficam em `web.json → foraDoTeste`, com o motivo. **Para o dono do teste (P01/P20):** aplicar a mesma tradução em `julgar()` e o extrator passa a mandá-las para `formas` (basta remover o desvio de `countSemSelect`).
4. **FileList apagado** (não estava na lista): `components/common/file/file-list.tsx` só era reexportado, nenhuma tela o usa, e pedia `tasksLayouts` (relação inexistente; 400 hoje, 500 antes do G1). Era a única forma real do web que o teste recusava.
5. **`*_INCLUDE` exportadas: 18 de 20.** As duas `ENTRY_DETAIL_INCLUDE` (questionário/avaliação) ficam locais — `hooks/index.ts` reexporta os dois módulos e o nome repetido quebra o `tsc` (TS2308). A `AIRBRUSHING_INCLUDE` de `budget/vehicles/use-budget-vehicles.ts` fica local (tela de N veículos, intocável até o P22). O extrator lê exportadas ou não. ⚠️ Exportar objeto de arquivo de componente faz o Fast Refresh recarregar o módulo inteiro no dev (aviso `react-refresh/only-export-components`); não muda nada em produção.
6. **O commit do código morto (`c33b1f76`) quebrava o `tsc`** sozinho: o recuo apagado devolvia `any` por face e a prévia de medidas lia `sections`/`photo` sem checar.
